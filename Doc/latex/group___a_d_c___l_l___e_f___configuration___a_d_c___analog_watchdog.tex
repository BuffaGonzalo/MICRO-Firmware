Get ADC analog watchdog monitored channel. 

\begin{DoxyNote}{Nota}
Usage of the returned channel number:
\begin{DoxyItemize}
\item To reinject this channel into another function LL\+\_\+\+ADC\+\_\+xxx: the returned channel number is only partly formatted on definition of literals LL\+\_\+\+ADC\+\_\+\+CHANNEL\+\_\+x. Therefore, it has to be compared with parts of literals LL\+\_\+\+ADC\+\_\+\+CHANNEL\+\_\+x or using helper macro \doxylink{group___a_d_c___l_l___e_m___h_e_l_p_e_r___m_a_c_r_o_ga11b528ebb75ee65deafce2dd57bb7569}{\+\_\+\+\_\+\+LL\+\_\+\+ADC\+\_\+\+CHANNEL\+\_\+\+TO\+\_\+\+DECIMAL\+\_\+\+NB()}. Then the selected literal LL\+\_\+\+ADC\+\_\+\+CHANNEL\+\_\+x can be used as parameter for another function.
\item To get the channel number in decimal format: process the returned value with the helper macro \doxylink{group___a_d_c___l_l___e_m___h_e_l_p_e_r___m_a_c_r_o_ga11b528ebb75ee65deafce2dd57bb7569}{\+\_\+\+\_\+\+LL\+\_\+\+ADC\+\_\+\+CHANNEL\+\_\+\+TO\+\_\+\+DECIMAL\+\_\+\+NB()}. Applicable only when the analog watchdog is set to monitor one channel. 
\end{DoxyItemize}
