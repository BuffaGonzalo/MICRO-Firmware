\doxysubsubsection{Descripción detallada}
Implementación de las rutinas de lectura I2C por DMA del MPU-\/6050. 

\begin{DoxyAuthor}{Autor}
Gonzalo M. Buffa 
\end{DoxyAuthor}
\begin{DoxyDate}{Fecha}
24/\+05/\+2025
\end{DoxyDate}
Este archivo implementa el puente de software entre la IMU MPU-\/6050 y el hardware I2\+C2 del STM32\+F103, gestionando las transferencias DMA para la lectura de 14 bytes y la reconstrucción de los enteros con signo de 16 bits sin bloquear la CPU.

Configuración aplicada sobre el sensor:
\begin{DoxyItemize}

\item {\ttfamily SMPLRT\+\_\+\+DIV} (0x19) = 0x04: Tasa de muestreo = 1000Hz / (1 + 4) = 200 Hz (período de 5 ms).
\item {\ttfamily CONFIG} (0x1A) = 0x02: Filtro pasa-\/bajos DLPF \texorpdfstring{$\sim$}{\string~}98 Hz (retardo mínimo 2.\+8 ms).

\item {\ttfamily GYRO\+\_\+\+CONFIG} (0x1B) = 0x00: Rango de giróscopo \$\textbackslash{}pm 250\texorpdfstring{$^\wedge$}{\string^}\textbackslash{}circ/\textbackslash{}text\{s\}\$ (131 LSB/(°/\+s)). \begin{DoxyPrecond}{Precondición}

\end{DoxyPrecond}
