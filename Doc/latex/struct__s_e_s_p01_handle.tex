\doxysubsubsection{Descripción detallada}
Estructura de funciones de bajo nivel requeridas por el driver ESP01. 

Permite la abstracción del hardware para que el driver controle el pin de habilitación del módulo y realice la lectura/\+escritura en la USART asignada.
