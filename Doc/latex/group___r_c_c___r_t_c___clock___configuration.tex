Macro to configure the RTC clock (RTCCLK). 

\begin{DoxyNote}{Nota}
As the RTC clock configuration bits are in the Backup domain and write access is denied to this domain after reset, you have to enable write access using the Power Backup Access macro before to configure the RTC clock source (to be done once after reset). 

Once the RTC clock is configured it can\textquotesingle{}t be changed unless the Backup domain is reset using \doxylink{group___r_c_c___r_t_c___clock___configuration_ga3bf7da608ff985873ca8e248fb1dc4f0}{\+\_\+\+\_\+\+HAL\+\_\+\+RCC\+\_\+\+BACKUPRESET\+\_\+\+FORCE()} macro, or by a Power On Reset (POR).
\end{DoxyNote}

\begin{DoxyNote}{Nota}
