Get ADC regular group conversion result. 

\begin{DoxyNote}{Nota}
Reading register DR automatically clears ADC flag EOC (ADC group regular end of unitary conversion). 

This function does not clear ADC flag EOS (ADC group regular end of sequence conversion). Occurrence of flag EOS rising:
\begin{DoxyItemize}
\item If sequencer is composed of 1 rank, flag EOS is equivalent to flag EOC.
\item If sequencer is composed of several ranks, during the scan sequence flag EOC only is raised, at the end of the scan sequence both flags EOC and EOS are raised. To clear this flag, either use function: in programming model IT: \doxylink{group___a_d_c___exported___functions___group2_ga28aaa5662eced92c5a4d23d8bd6b29ca}{HAL\+\_\+\+ADC\+\_\+\+IRQHandler()}, in programming model polling: \doxylink{group___a_d_c___exported___functions___group2_gad9c0b5763ab75357407e22d310befc30}{HAL\+\_\+\+ADC\+\_\+\+Poll\+For\+Conversion()} or \doxylink{group___a_d_c___exported___macros_gafe44e1e66141bca3665bb82981a81a17}{\+\_\+\+\_\+\+HAL\+\_\+\+ADC\+\_\+\+CLEAR\+\_\+\+FLAG(\&hadc, ADC\+\_\+\+FLAG\+\_\+\+EOS)}. 
\end{DoxyItemize}
\end{DoxyNote}

Enables ADC, starts conversion of regular group and transfers result through DMA. 

Interruptions enabled in this function:
\begin{DoxyItemize}
\item DMA transfer complete
\item DMA half transfer Each of these interruptions has its dedicated callback function. \begin{DoxyNote}{Nota}
For devices with several ADCs: This function is for single-\/\+ADC mode only. For multimode, use the dedicated Multimode\+Start function. 

On STM32\+F1 devices, only ADC1 and ADC3 (ADC availability depending on devices) have DMA capability. ADC2 converted data can be transferred in dual ADC mode using DMA of ADC1 (ADC master in multimode). In case of using ADC1 with DMA on a device featuring 2 ADC instances: ADC1 conversion register DR contains ADC1 conversion result (ADC1 register DR bits 0 to 11) and, additionally, ADC2 last conversion result (ADC1 register DR bits 16 to 27). Therefore, to have DMA transferring the conversion results of ADC1 only, DMA must be configured to transfer size: half word. 
\end{DoxyNote}
