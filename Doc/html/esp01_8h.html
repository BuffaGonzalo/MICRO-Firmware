Descripción detallada

Driver de comunicación por comandos AT para módulo Wi-Fi ESP8266 (ESP-01).

Autor
Germán E. Hachmann / Gonzalo M. Buffa
Fecha
04/08/2024

Este módulo implementa el control asíncrono del transceptor Wi-Fi ESP-01 a través de USART, gestionando la máquina de estados de conexión a puntos de acceso (Modo Station), la creación de redes locales (Modo SoftAP), la apertura de sockets UDP/TCP para telemetría y el servidor HTTP embebido para configuración remota.

Transmite un bloque de datos del buffer circular a través del socket activo.

Parámetros
[in]connIDIdentificador del canal/conexión (0 para modo Station único; ID de cliente en SoftAP/WebServer).
[in]bufPuntero al buffer de memoria que almacena los datos.
[in]irRingBufÍndice de lectura actual en el buffer circular.
[in]lengthCantidad de bytes a transmitir.
[in]sizeRingBufTamaño total del buffer circular para gestión de wrap-around.
Precondición
Socket conectado (ESP01_UDPTCP_CONNECTED) y transmisor no ocupado (ESP01_SEND_READY).
Postcondición
Encola el comando AT+CIPSEND y conmuta a ESP01_SEND_BUSY.
Valores devueltos
ESP01_SEND_READYTransmisión encolada correctamente hacia el módulo.
ESP01_SEND_BUSYTransmisor ocupado con un envío previo.
ESP01_SEND_ERRORFallo al procesar el comando AT de envío.

[in]lengthCantidad de bytes a transmitir.

Conexión establecida (UDPTCPCONNECTED == 1 o esp01SoftAPMode == 1) y canal listo.
Postcondición
Carga el comando AT+CIPSEND en el buffer de transmisión TX y activa la bandera SENDINGDATA.

void ESP01_Task ( void )

Tarea principal de procesamiento de la máquina de estados AT.

Tarea principal periódica de la máquina de estados AT del driver ESP-01.

Debe ser llamada continuamente en el bucle principal (main) para analizar las respuestas recibidas por USART (OK, ERROR, +IPD, etc.) y gestionar envíos.

Tarea principal de procesamiento de la máquina de estados AT.

Coordina tres subprocesos fundamentales de manera no bloqueante:

  1. ESP01ATDecode(): Decodifica cadenas entrantes por USART (OK, ERROR, +IPD, etc.).
  2. ESP01DOConnection(): Avanza la MEF de inicialización, asociación Wi-Fi y apertura de sockets.
  3. ESP01SENDData(): Gestiona el protocolo de despacho de paquetes (AT+CIPSEND).
Precondición
El driver debe estar inicializado mediante ESP01_Init() y ejecutarse en el super-loop.
Postcondición
Puede alterar el estado de conexión del robot (ESP01ChangeState), los buffers y flags AT.
