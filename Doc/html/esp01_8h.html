Descripción detallada

Driver de comunicación por comandos AT para módulo Wi-Fi ESP8266 (ESP-01).

Autor
Germán E. Hachmann / Gonzalo M. Buffa
Fecha
04/08/2024

Este módulo implementa el control asíncrono del transceptor Wi-Fi ESP-01 a través de USART, gestionando la máquina de estados de conexión a puntos de acceso (Modo Station), la creación de redes locales (Modo SoftAP), la apertura de sockets UDP/TCP para telemetría y el servidor HTTP embebido para configuración remota.

Configura el módulo en modo Dual (Station + SoftAP) y levanta un servidor Web HTTP.

Configura el ESP01 en modo SoftAP + inicia servidor HTTP en puerto 80.

El módulo crea un punto de acceso inalámbrico propio en el canal especificado y abre un socket servidor TCP en el puerto 80 para permitir la configuración mediante una página HTML interactiva.

Parámetros
[in]apSSIDNombre (SSID) de la red inalámbrica que emitirá el robot.
[in]apPassContraseña del SoftAP (mínimo 8 caracteres, o NULL/"" para red abierta).
[in]chCanal de radiofrecuencia Wi-Fi (1 a 13).
[in]encTipo de autenticación: 0=Abierta, 2=WPA, 3=WPA2, 4=WPA/WPA2.

Configura el módulo en modo Dual (Station + SoftAP) y levanta un servidor Web HTTP.

El STM32 podra recibir peticiones HTTP con SSID y contraseña para luego llamar a ESP01_SetWIFI() y conectarse como Station.

Parámetros
apSSIDNombre de la red WiFi a crear
apPassContraseña del AP (minimo 8 chars). NULL o "" para red abierta
chCanal WiFi (1-13)
encEncriptacion: 0=abierta, 2=WPA, 3=WPA2, 4=WPA/WPA2
