◆ CDC_Receive_FS()

int8_t CDC_Receive_FS ( uint8_t * Buf,
uint32_t * Len )
static

#include "usbd_cdc_if.c"

Data received over USB OUT endpoint are sent over CDC interface through this function.

Nota
This function will issue a NAK packet on any OUT packet received on USB endpoint until exiting this function. If you exit this function before transfer is complete on CDC interface (ie. using DMA controller) it will result in receiving more data while previous ones are still not sent.
Parámetros
BufBuffer of data to be received
LenNumber of data received (in bytes)
Valores devueltos
Resultof the operation: USBD_OK if all operations are OK else USBD_FAIL
