Archivo de configuración estática para el driver de pantalla OLED SSD1306.

Autor
Olivier Van den Eede / Aleksander Alekseev / Gonzalo M. Buffa

Selecciona la familia de microcontrolador (STM32F1), el bus de comunicaciones (I2C a dirección 0x3C), y las tipografías habilitadas en memoria Flash (Font_7x10 y Font_11x18) para minimizar el uso de ROM.
