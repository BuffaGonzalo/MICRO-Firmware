Este archivo contiene las funciones de serialización, cálculo de Checksum por XOR, gestión de punteros circulares e implementación de la máquina de estados finita para la detección y validación de tramas de telemetría y telemando.

uint8_t unerPrtcl_DecodeHeader ( _sComm * dataRx)

Decodifica secuencialmente la cabecera y el payload de tramas entrantes.

Ejecuta la máquina de estados de decodificación de cabeceras sobre los datos recibidos.

Implementa una máquina de estados para detectar el preámbulo "UNER:". Una vez localizado el delimitador ':', extrae el payload restando bytes hasta llegar al último, el cual debe coincidir con el checksum acumulado.

Parámetros
[in,out]dataRxPuntero a la estructura de recepción _sComm.
Devuelve
1 si se completó una trama con checksum válido, 0 en caso contrario.
Precondición
Bytes disponibles en el buffer circular.
Postcondición
indexR avanza hasta consumir la trama o los datos actuales. indexData apunta al comando.

Decodifica secuencialmente la cabecera y el payload de tramas entrantes.

Procesa los bytes acumulados entre indexR e indexW. Verifica el preámbulo "UNER:", contabiliza los bytes recibidos y valida el Checksum al final del payload.

Parámetros
[in,out]dataRxPuntero a la estructura de recepción _sComm.
Precondición
El buffer debe contener bytes no leídos (indexR != indexW).
Postcondición
Modifica indexR, header, indexData y chk. Si retorna TRUE, indexData apunta al comando.
Valores devueltos
1(TRUE) Trama completa y válida recibida con Checksum verificado.
0(FALSE) Trama incompleta, datos en proceso o error de sincronización.

Escribe el encabezado estructurado del protocolo UNER en el buffer de transmisión.

Escribe el encabezado estándar del protocolo UNER en el buffer de transmisión.

Secuencia inyectada:

  1. Sync chars: 'U', 'N', 'E', 'R'
  2. Longitud total: frameLength + 1
  3. Delimitador: ':'
  4. Identificador de comando: ID Calcula el Checksum preliminar mediante XOR acumulado sobre todos los campos.
    Parámetros
    [in,out]dataTxPuntero a la estructura de transmisión _sComm.
    [in]IDIdentificador del comando según _eCmd.
    [in]frameLengthCantidad de bytes en la carga útil (sin contar cabecera).
    Devuelve
    Checksum XOR calculado para la cabecera.
    Precondición
    El buffer dataTx debe estar inicializado y poseer al menos 7 bytes disponibles.
    Postcondición
    indexW avanza 7 bytes en el buffer circular y dataTx->chk contiene el XOR parcial.
