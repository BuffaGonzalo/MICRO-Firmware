Get ADC multimode configuration to operate in independent mode or multimode (for devices with several ADC instances).

Nota
If multimode configuration: the selected ADC instance is either master or slave depending on hardware. Refer to reference manual. @rmtoll CR1 DUALMOD LL_ADC_GetMultimode
