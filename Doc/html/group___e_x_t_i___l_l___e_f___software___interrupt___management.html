Generate a software Interrupt Event for Lines in range 0 to 31.

Nota
If the interrupt is enabled on this line in the EXTI_IMR, writing a 1 to this bit when it is at '0' sets the corresponding pending bit in EXTI_PR resulting in an interrupt request generation. This bit is cleared by clearing the corresponding bit in the EXTI_PR register (by writing a 1 into the bit) @rmtoll SWIER SWIx LL_EXTI_GenerateSWI_0_31
