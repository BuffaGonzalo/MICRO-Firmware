309 * @param __HANDLE__: DMA handle
310 * @param __INTERRUPT__: specifies the DMA interrupt sources to be enabled or disabled.

322 * @param __INTERRUPT__: specifies the DMA interrupt sources to be enabled or disabled.
323 * This parameter can be any combination of the following values:
324 * @arg DMA_IT_TC: Transfer complete interrupt mask

327 * @retval None
328 */

333 * @param __HANDLE__: DMA handle

336 * @arg DMA_IT_TC: Transfer complete interrupt mask

339 * @retval The state of DMA_IT (SET or RESET).
