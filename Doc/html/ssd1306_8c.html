Descripción detallada

Implementación del controlador y primitivas de dibujo para el display OLED SSD1306.

Autor
Olivier Van den Eede / Aleksander Alekseev / Gonzalo M. Buffa

Gestiona el volcado asíncrono página por página mediante transferencias I2C DMA, la manipulación directa de bits dentro del framebuffer y algoritmos gráficos clásicos (algoritmo de trazado de líneas de Bresenham, círculos, rectángulos e inversión de color).

◆ ssd1306_Init()

void ssd1306_Init ( void )

Inicializa el controlador SSD1306 con la secuencia de encendido y parámetros de display.

Configura la bomba de carga DC-DC (0x8D), el oscilador interno (0xD5), el multiplexado a 64 filas (0xA8) y limpia el buffer interno de memoria en RAM.

Precondición
I2C2 inicializado y funciones de enlace configuradas.
Postcondición
Enciende la pantalla y borra el framebuffer; SSD1306.Initialized pasa a 1.

◆ ssd1306_UpdateScreenDMA()

char ssd1306_UpdateScreenDMA ( void )

Ejecuta el volcado asíncrono no bloqueante del framebuffer vía transferencias DMA.

Máquina de 4 estados para actualizar las 8 páginas (1024 bytes) mediante I2C DMA:

  • Estado 1: Envía comando de direccionamiento de página (0xB0 + page).
  • Estado 2: Envía comando de columna baja (0x00 + offset).
  • Estado 3: Envía comando de columna alta (0x10 + offset).
  • Estado 4: Transfiere los 128 bytes de la página actual vía DMA.
Devuelve
1 al completar la transmisión de las 8 páginas (frame completo desplegado); 0 si la transferencia sigue en curso.
Precondición
Función ssd1306_Attach_MemWriteDMA vinculada y bandera SSD1306_TxCplt registrada.
Postcondición
Actualiza los estados internos ssd1306_dma_state y ssd1306_dma_current_page.
Ver también
ssd1306_ResetDMAState
