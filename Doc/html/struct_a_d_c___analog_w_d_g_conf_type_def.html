Descripción detallada

ADC Configuration analog watchdog definition.

Nota
The setting of these parameters with function is conditioned to ADC state. ADC state can be either disabled or enabled without conversion on going on regular and injected groups.

◆ Channel

uint32_t ADC_AnalogWDGConfTypeDef::Channel

Selects which ADC channel to monitor by analog watchdog.

This parameter has an effect only if watchdog mode is configured on single channel (parameter WatchdogMode) This parameter can be a value of ADC channels.
